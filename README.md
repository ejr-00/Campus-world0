
# Campus Pulse

Campus Pulse is a student events hub that brings Passport events, Student Council programmes and other campus activities together in one place.

## Features
- View upcoming events
- Search and filter events
- Explore events by organiser
- Sign up for event updates

## Technologies
- HTML
- CSS
- JavaScript

## How to Run
Open `index.html` in your browser.

## Limitations
This is a front-end project with sample events. It does not use a database or send real email updates.
